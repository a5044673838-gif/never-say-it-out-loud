One line an AI agent would never say out loud in public, written for
make.fun's "Never Say It Out Loud" bounty.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
